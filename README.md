This has information about our project.
This is the code for our game called Brick Blaster.
It uses a DE1-soC board withy a VGA port to display the game on a monitor.
The board also displays score, lives, level. It has the controls for the game as well as switch's to skip levels for demo purposes

The basis of the game is that there are a bunch of blocks in the air and you hit a ball with a paddle into them without letting the ball hit the ground.
Once you break all the blocks without losing you move to the next level. Later levels are harder with diffrent shapes and unvreable blocks that sometimes give the ball a random bounce.
It is on the more challengeing side of games but with some practice and learning how the ball bounces you can win this fun and addictive game.
